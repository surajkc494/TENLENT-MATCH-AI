# TENLENT-MATCH-AI

TalentMatch AI is an AI-powered Resume & Job Description Matching System that helps recruiters and job seekers evaluate candidate-job compatibility using Generative AI and semantic analysis.

## Features

- 📄 Resume PDF Upload
- 🤖 AI-based Resume Parsing
- 📝 Job Description Analysis
- 🎯 Semantic Resume-JD Matching
- 📊 Explainable Match Score
- 🔍 Skill Gap Analysis
- 💡 AI-Powered Resume Improvement Suggestions

## Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **AI:** Google Gemini 2.5 Flash
- **PDF Parsing:** pdf-parse, Multer
- **API:** REST APIs
- **Tools:** Git, GitHub, VS Code, GitHub Copilot

## Workflow

1. Upload Resume (PDF)
2. Enter Job Description
3. AI extracts resume & JD information
4. Semantic matching is performed
5. Match score is calculated
6. Skill gaps are identified
7. AI generates recommendations
